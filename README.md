# AnyRPG UMA Addon

## Introduction

This is the UMA addon for AnyRPG.

It adds the following features and functionality:
* UMA male and female player characters
* UMA template content that includes UMA NPCs
* UMA character editor with DNA and slot customization
* An UMA demo game to demonstrate how it all works with AnyRPG

## Installation

This addon can be installed via the Welcome Window in AnyRPG.

https://github.com/AnyRPG/AnyRPGCore
